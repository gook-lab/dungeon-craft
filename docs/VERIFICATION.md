# DungeonCraft 검증 방법

DungeonCraft는 전투 규칙, 월드맵 연결성, 선택에 따른 분기를 렌더러와 분리해 검사합니다. 자동 검사는 콘텐츠 오류를 찾고, 실제 플레이는 대사와 전투 흐름이 자연스러운지 확인합니다.

## 기본 검증

```bash
npm test
npm run build
```

Vitest는 순수 전투 리졸버, 진행 규칙, 포탈 참조, 충돌 데이터를 사용한 도달 가능성, 스프라이트 참조를 확인합니다.

## 전투 밸런스 비교

```bash
npm run balance
```

하네스는 지역과 보스별 권장 레벨·장비·소모품 조건을 사용해 자동 전투를 반복합니다. `BASELINE`, `MERCY`, `RUTHLESS` 세 조건에서 평균 라운드와 사망 수를 비교합니다.

승률이 모두 높게 나오는 구간에서는 승률만으로 차이를 판단하지 않습니다. 평균 라운드가 지나치게 짧아졌는지, 특정 선택 성향에서 사망 수가 급격히 늘었는지 함께 확인합니다.

## 월드맵 연결성

맵 테스트는 다음 순서로 오류를 찾습니다.

1. 각 포탈이 존재하는 맵과 착지 가능한 칸을 가리키는지 확인합니다.
2. 실제 필드와 같은 충돌 데이터를 사용해 스폰 지점부터 포탈·보스·상자까지 탐색합니다.
3. NPC와 보스의 스프라이트 참조가 실제 에셋으로 연결되는지 확인합니다.

포스트게임 워프 전용 지역은 일반 포탈 그래프의 도달성 대상에서 제외되지만, 포탈 참조와 맵 내부 통행성 검사는 그대로 적용됩니다.

## 수동 플레이 확인

- 적을 살려 보내거나 처치한 결과가 이후 대사와 경로에 반영되는지
- 동료 영입과 유대 상태가 저장 후에도 유지되는지
- 분기 보스를 처리한 결과가 올바른 포탈을 여는지
- 엔딩 이후 이어하기가 포스트게임 상태로 복구되는지
